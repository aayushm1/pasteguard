How it works

Three things happen in under a millisecond

01 · Catch

You paste as usual

PasteGuard checks the clipboard text before the chat box receives it. No new habit, no extra click.

02 · Mask

Sensitive values become placeholders

[EMAIL_1], [CLIENT_1]… The same value always gets the same placeholder, so the AI's answer still makes sense.

03 · Restore

You read the real values

When the reply mentions a placeholder, PasteGuard swaps the real value back on your screen only. Copy the reply and you get the real values too.

What it catches

Understands context, not just patterns

Card numbers are Luhn-checked and IBANs and Aadhaar numbers checksum-validated. Context rules catch what patterns can't: “CVV 123”, “client ID HLX-00482”, “finance officer Rohan Deshmukh”. Once a name or company is found, every later mention is masked too. Order numbers, dates and version numbers are left alone.

Install

Up and running in a minute

Chrome Web Store Coming soon

One-click install is on the way. Until then, use the manual install. It takes about a minute.

Manual install (Chrome, Edge, Brave, Arc)

  1. ⬇ Download PasteGuard (.zip) and unzip it.
  2. Open chrome://extensions and switch on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped pasteguard folder.
  4. Pin the 🛡️ icon. Paste something into ChatGPT to see it work.

FAQ

Questions

Does PasteGuard send my data anywhere?

No. There's no server. The extension has no network permissions beyond the AI sites it runs on, and it makes no requests of its own.

What if I actually want to paste something unmasked?

Click “Allow next paste unmasked” in the notification and paste again, or switch PasteGuard off from the toolbar icon.

Does it catch names?

Yes, from context: titles (“Dr. Ananya Rao”), roles (“finance officer Rohan Deshmukh”), labels (“Name: …”), greetings, common first names, and names implied by email addresses. Company names are caught from suffixes (“Inc”, “Labs”, “Biosciences”) and email domains. Once found, every later mention is masked. For anything unusual, add it to “Always mask”.

Does it mask text I type?

Version 0.1 masks pastes, which is where bulk sensitive data comes from (emails, tickets, spreadsheets). Typed-text scanning is planned.

Is it a replacement for my company's security tools?

No. It's a seatbelt for everyday use. It catches common sensitive values but can't guarantee it catches everything.
